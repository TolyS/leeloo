Privacy policy

Last updated: 17 November 2026.

Leeloo is a personal assistant used by one person, the owner of the Google account it connects to. No other users are served.

Data accessed

  • Gmail: read-only access (gmail.readonly) to find and summarise the owner's messages. Leeloo cannot send, delete or modify email.
  • Google Calendar: access (calendar) to read events and, only on the owner's explicit request, create or change them.

Use, storage and sharing

  • Data is used only to answer the owner's own requests and reminders.
  • OAuth tokens are stored on the owner's private server with owner-only file permissions.
  • Data is not sold, shared with third parties, or used for advertising. Message content may be processed by the AI model provider the owner has chosen, solely to produce the owner's responses.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
